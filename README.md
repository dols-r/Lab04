Свойство Environment.ProcessorCount в .NET возвращает количество логических, а не физических процессоров, доступных текущему процессу. Поэтому сравнивать его имеет смысл именно с числом логических процессоров. Физическое ядро - это отдельный аппаратный блок вычислений, логический процессор - это независимый поток выполнения внутри этого ядра.

# Итоговый вопрос

Это не является противоречием, потому что свойство Environment.ProcessorCount возвращает количество логических процессоров, а не физических ядер.

# Контрольные вопросы

1. Environment.ProcessorCount показывает количество логических процессоров данного компьютера.
2. Физическое ядро - это аппаратный блок внутри процессора, который имеет свои вычислительные части и кэш. Логический процессор - это виртуальное ядро (поток выполнения), который находится внутри физического ядра.
3. Увеличение количества потоков может увеличить загрузку CPU, потому что процессор получает больше задач для одновременного выполнения.
4. После некоторого количества потоков загрузка не обязательно продолжает расти, потому что основная нагрузка приходится только на некоторые из них, и получается, что при увеличении потоков снимается часть нагрузки с предыдущего количества потоков и распределяется на остальные. А после превышения количества потоков числа логических процессоров загрузка так и останется 100%, но упадёт производительность компьютера.
5. Частота процессора может изменяться во время работы, потому что её изменение зависит от нагрузки, которую несёт выполнение программы. Частота изменяется при автоматическом разгоне (начало выполнения) и ограничивается физическими возможностями компьютера (ограничивается энергосбережением, защитой от перегрева)
